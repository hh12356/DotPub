## DotPub部署上线记录

其实这一个小项目不需要采用docker和CICD
但我力求熟悉真实开发流程，采取了最普遍的做法

其实过程中大多时间都是AI指挥我干活，但我也在不断调试中理解整个部署上线流程

看到DotPub能用公网IP访问，我犹若打开了新世界的大门
这无疑会成为一张很棒的名片，或是漫长面试中的很有意思的谈资

用docker部署上线后，想要更新还是很麻烦的，使用的指令也大都重复
于是继续引进了CICD，在git push后自动触发部署到服务器，实现了远程仓库和服务器版本的统一

整个配置过程麻烦且耗时，大多源于网络问题，我采用了多种方案：先尝试使用ghcr，发现连接不稳定后改用普遍方案ACR
配置成功后从push完成到成功更新上线耗时大约15分钟

至此，DotPub项目正式完结
整体来看，整个开发流程虽然简单，但是完整
公网ip访问会开放十天左右
